## 2.1 — CHARACTER CREATION (p.9–10)

### Vue d'ensemble (p.10)

Avant de jouer, créer un **Played Character (PC)** avec :
- Une **Origin** (background + abilities) → p.11
- Un **Role** (expertise + special abilities) → p.22
- Un **Starship** → p.25

Chaque personnage commence avec **2 Health Packs** et **50 Scope**.

### Les 3 Character Sheets (p.10)

| # | Feuille | Contenu | Partagée ? |
|---|---|---|---|
| 01 | **Player Sheet** | Stats, équipement, abilities du PC | Non — chaque joueur la sienne |
| 02 | **Starship Sheet** | Vaisseau, équipage, connections | Oui — partagée entre joueurs |
| 03 | **Star System Map** | Carte hex, découvertes, points d'intérêt | Oui — partagée en multijoueur |

### Modes de jeu (p.13)

**Campaign Mode** — explore 3 Star Systems enchaînés. Difficulté croissante. Les choix de factions dans chaque système impactent les suivants.

**Multiplayer** — jeu coopératif sans GM obligatoire. Le livre gère les événements automatiquement. Option : un joueur peut prendre le rôle de GM.

> Avant la première session : discuter des attentes, du ton de l'aventure, des backgrounds des personnages et de la stratégie de départ.

## 2.4 — STATS & ROLLS (p.15–16)

### Les 4 Stats

| Stat | Domaines |
|---|---|
| **VIGOR** | Force, survie, action physique directe |
| **GRACE** | Pilotage, esquive, furtivité, évasion, précision |
| **MIND** | Planification, hacking, raisonnement, connaissances, machines |
| **TECH** | Fabrication, réparation, utilisation de technologie |

### Ressources

**HEALTH** — Condition physique du personnage. À 0 → roll vie/mort.

**ENERGY** — Utilisée pour les abilities MIND ou CYBERTECH. Restaure 3 Energy quand on atteint 0 Health.

**ARMOR** — Réduit les dégâts reçus.

**HYPERDRIVE** — Jauge spéciale. Dépenser pour :
- Booster n'importe quel roll de +1
- Infliger les dégâts **maximaux** avec une attaque
- Utiliser une ability cybernétique MAX sans payer le coût Energy

→ Se réinitialise après un **Rest**.

**STATUS TRACKER** — Suivi des conditions de statut actives.

### Ressources économiques (p.16)

| Ressource | Usage |
|---|---|
| **EXP** | Gagné en battant des ennemis. Dépensé pour les implants Cybertech et modules Starship |
| **Serum** | Monnaie universelle. Départ : **3#** |
| **Favor** | Relation avec chaque faction (positive ou négative) |

### Cybertech (p.16)

Implants installés sur le personnage pour augmenter les stats et débloquer des abilities. Coûtent de l'**EXP**. Achat/retrait chez les **Cyber Docs**.

### Challenge Rolls (p.16)

```
[ Dé ] + [ Modificateur ]  vs  [ Dé de Difficulté ]
```
Réussi si résultat **≥ difficulté**. Le résultat le plus haut compte.

### Story Choices (p.16)

| Symbole | Type |
|---|---|
| **►** | Option confiante — choisir une seule |
| Normal | Option standard |
| **📖** | Composante narrative — lire un passage du livre (+4 Story Power) |

## 2.5 — STAR SYSTEM MAP (p.17–18)

### Structure de la carte (p.17)

- **36 Location Hexes** au total
- Codes de localisation : format **A3, B5**
- Étoile centrale = inaccessible mais toujours présente
- Hexs organisés en rings autour de l'étoile

### Faction Strength (p.17)

Chaque faction possède une **Faction Strength** de 0 à **3 max**. Toutes commencent à 0. Définit la présence territoriale sur la carte.

### Types de lieux (p.18)

| Icône | Lieu |
|---|---|
| Settlement | Base habitée |
| Hostile World | Monde hostile |
| Neutral World | Monde neutre |
| Planet | Planète |
| Planet & Satellite | Planète + 1 satellite |
| Planet & 2 Satellites | Planète + 2 satellites |
| Asteroid | Astéroïde |
| Research Station | Station de recherche |
| Helion Station | Station Helion |
| Pirate Hideout | Repaire de pirates |
| Forest Planet | Planète forêt |
| Void Planet | Planète vide |
| Colony Shop | Boutique de colonie |

### Navigation (p.18)

Directions cardinales : **N, NE, E, SE, S, SW, W, NW**

Tuiles adjacentes numérotées **1–6** dans le sens horaire (1 = Nord). Si la tuile cible est occupée, placer dans la plus proche en partant de 1.

## 2.6 — CONNECTIONS (p.19–20)

### Système de Connections

Personnages rencontrés pouvant devenir des alliés. Suivi via l'**Affinity** (affinité).

- **5 Affinity** → peut recruter la connection dans l'équipage
- Affinity gagnée en aidant un personnage ou complétant des missions pour lui

### Social Stats

| Stat | Domaines |
|---|---|
| **Allure** | Charisme, attraction, intimidation |
| **Acuity** | Street smarts, réflexes mentaux |
| **Skill** | Élégance, diplomatie, tromperie |

### Social Rolls

Utiliser l'**Oracle** pour les rencontres sociales + **Challenge Roll** pour résoudre les conflits sociaux.

### Recrutement (p.19)

- Via **Affinity** (5 points) → inviter à l'équipage
- Via **embauche** dans un hub crewmember → **150 pts** par membre

## 2.7 — CREWMEMBERS (p.21–24)

### Composition de l'équipage (p.21–22)

- Maximum **4 crewmembers** (PC inclus)
- Rôles disponibles : **PILOT · MEDIC · MECHANIC-NAVIGATOR · GUNNER-MARINE**
- Première partie : recommandé PILOT ou MEDIC

### Chaque crewmember possède (p.22)

| Élément | Détail |
|---|---|
| **1 Passive Skill** | Bénéfice permanent tout au long du jeu |
| **Jusqu'à 3 Active Skills** | 1 utilisation par cycle. Coûte une action Cycle en combat |
| **6 Inventory Slots** | Échangeables librement sauf Titan crew |
| **HP** | Mort à 0 |

### Actions crewmembers (p.23)

| Action | Effet |
|---|---|
| QUICK FIX | Répare 15 Hull / dépenser 2 Fuel pour +15 Hull |
| CALIBRATE / RELOAD | Recharger arme ou reconfigurer système ship |
| BARREL ROLL | Dépenser 2 Fuel → +d6 bonus d'évasion contre toutes attaques ce tour |
| FONT AID | Dépenser 2b → restaure 1d4+1d4 HP (soi ou allié) |
| ASTROLINK | Dépenser 1 Fuel → gagner une action pendant 2 tours |
| STAR BYSTANT | Dépenser 2 Fuel en zone Settlement → action récupération/ravitaillement |
| LASER BOMB | Attaque énergie zone |
| MISSILE MACHINE | Attaque missile portée moyenne, +d6 dégâts |
| KAMA-SHIELD | 1AP si ship >1 zone de vie → réduire prochain dégât entrant |

## 2.9 — STARSHIP SHEET (p.25–26)

### Stats du vaisseau (p.25)

| Stat | Valeur | Règle |
|---|---|---|
| **Hull** | **10** | 1 Hull perdu par point de dégât. À 0 → ship détruit |
| **Fuel** | Variable | **1 Fuel** dépensé par hex déplacé. À 0 → ship stranded |
| **Cargo Hold** | **6 items max** | Accessible pendant le combat spatial |

### Profils pré-construits (p.25)

- Vector Ace Fighters
- Smuggler Speeder
- Roughed Speeder
- Droned Interceptor

### Modules du vaisseau (p.26)

**6 slots** :
- 1 slot **Control** (passif)
- 1 slot **Engines** (passif)
- 4 slots **Open** (Systems & Weapons — actifs via Action Die)

**Création du vaisseau** :
1. Aller à la section Starship Modules
2. Choisir **3 modules Tier 1** : 1 Control + 1 Engines + 1 au choix
3. Noter les effets sur le Starship Sheet

**Upgrades** : remplacer modules de même type. Vendre/changer design en **Starport** (Scraps & CR).

## 2.10 — TRAVEL RULES & PLAYER ADVICE (p.27–28)

### Règles de voyage (p.27)

**Settlements** : bases de ravitaillement, hébergent des Faction Headquarters. Permettent le refuel.

**Hexs déjà explorés** : option de ne pas re-explorer, continuer à rouler sur la table de rencontres.

**Attacking non-hostiles** : pénalités de Favor :

| Situation | Pénalité |
|---|---|
| Attaquer membre de faction | **-2 Favor** |
| Attaquer membre directement | **-3 Favor** |
| Attaquer en solo/neutre | **-4 Favor** + réaction immédiate de la faction |

**Stats des personnages sans profil** :

| Type | Stats |
|---|---|
| Scientist | Fearlessness, Intelligence |
| Soldier | Fearlessness, Intelligence, Strength |
| Automaton | Body, Intelligence |
| Android / Synth | Full Intelligent stats |
| Mutated Creatures | Large Alien Assets |

### Conseils joueurs (p.28)

| Conseil | Message |
|---|---|
| **Fill the Map** | Documenter chaque découverte sur la Star System Map |
| **Ask the Oracle** | Utiliser l'Oracle pour toute incertitude narrative |
| **Be Tribal** | S'engager avec une faction, éviter la neutralité passive |
| **Make Connections** | Établir des relations — elles peuvent sauver la mise |
| **Roleplay First** | Rester dans le personnage, ne pas se perdre dans les stats |
| **Escape Danger** | Savoir fuir — connaître les limites du personnage |
